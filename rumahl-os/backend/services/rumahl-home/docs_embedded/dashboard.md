# Dashboard im Überblick

Das rumahl Dashboard ist die Haupt-Benutzeroberfläche für Bewohner
und Administratoren. Es vereint Echtzeit-Status, Steuerung und
Konfiguration in einem einzigen, durchgängig animierten Interface.

## Bereiche

- **Home** — Schnellzugriff auf Räume, Szenen und Lieblings-Entitäten.
- **Geräte** — Liste aller Home-Assistant-Entitäten mit Filter und Suche.
- **Automationen** — Visualisierung und Auslöser-Verlauf aller
  HA-Automationen.
- **Plugins / Apps** — Installierte Erweiterungen verwalten.
- **Admin Panel** — Systemverwaltung (siehe eigener Abschnitt).
- **Dokumentation** — diese Seite.

## Tipps

- Klick auf den Tooltip eines Reglers blockiert *nicht* mehr die
  darunterliegenden Bedienelemente (`pointer-events: none` ist gesetzt).
- Über die globale Konfiguration lassen sich Sprache, Theme und
  Standort-Sync zentral steuern.
