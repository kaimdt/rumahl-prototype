# Willkommen bei rumahl OS

rumahl OS ist ein vollständig integriertes Smart-Home Betriebssystem,
das alle Bausteine (Dashboard, Home-Assistant-Bridge, App-Store,
Plugin-Sandbox, Updates und Sicherheit) in einer einzigen, schlanken
Plattform vereint.

Diese eingebettete Dokumentation steht immer zur Verfügung — auch
wenn keine externe Doku-Bundle gemountet ist. Für eine ausführlichere
Dokumentation legen Sie eine `docs/docs-config.json` mit zugehörigen
Markdown-Dateien neben das `rumahl-home`-Binary; sie wird dann anstelle
dieser Basis-Doku ausgeliefert.

## Schnellstart

1. **Admin Panel** öffnen — über das Zahnrad-Symbol oben rechts.
2. **Globale Konfiguration** → grundlegende Einstellungen prüfen
   (System, Home Assistant, Darstellung, Privatsphäre, Entwickler).
3. **HA Config** → Home-Assistant URL und Long-Lived Access Token
   hinterlegen.
4. **Dienste** → Status der einzelnen rumahl-Microservices kontrollieren.

Viel Spaß!
